# Job Tracker — Job Application Management System

A web-based job application tracking system built using **HTML, CSS, and TypeScript** to help job seekers organise applications, manage tasks, and keep track of follow-ups throughout their job search.

## Live Demo

[Try Job Tracker](https://shahanangit.github.io/job-tracker/)

Explore the live application to view the dashboard and try its job application management features.

## Overview

Job Tracker provides a centralised dashboard for organising job applications and related activities. It focuses on simplifying the job search process through structured application records, status tracking, and task management.

## Features

- **Job Application Management:** Add, view, edit, and delete job application records.
- **Application Status Tracking:** Organise applications according to their progress.
- **Task Management:** Manage job-related tasks using To-Do and Completed sections.
- **Follow-up Reminders:** Keep track of important follow-up activities.
- **Progress Overview:** View job search activity and weekly progress.
- **Responsive Frontend:** A clean interface built with HTML and CSS.

**Development status:** The application loads successfully and passes TypeScript compilation. Individual feature testing and responsive layout verification are ongoing.

## Getting Started

### Prerequisites

- Node.js and npm
- A modern web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/shahanangit/job-tracker.git
cd job-tracker
```

**2. Install dependencies**

```bash
npm install
```

**3. Compile TypeScript**

```bash
npm run build
```

**4. Run the application**

Open `index.html` using a local development server, such as VS Code's Live Server extension.

### TypeScript Validation

Run the following command to check TypeScript code without generating output files:

```bash
npm run check
```
